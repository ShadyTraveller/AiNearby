# AI Nearby — ainearby.co

Find local AI pros / services near you. Small, mobile-first, static site — no database, no Supabase.

- `index.html` — the whole site (search, Near me, Match Me, 12 service categories, list-your-service)
- Hosted free: GitHub Pages from `main`, plus Vercel via `.github/workflows/main.yml` (push to `master` triggers the Vercel deploy action).
- Custom domain: point `ainearby.co` at the host (see Vercel / Pages domain settings).

To update: edit `index.html` and push to `main` (and `master` for Vercel).
